# FindHub

אבטיפוס ראשוני לפלטפורמה ישראלית להשוואת מוצרים ומפרטים. **כל המוצרים והמחירים כרגע הם נתוני הדגמה פיקטיביים**, ללא מחירי חנויות חיים.

## הרצה

```bash
npm install
npm run dev
```

פתחו http://localhost:3000

## מה קיים
- ממשק עברי RTL ורספונסיבי
- חיפוש וסינון קטגוריות
- השוואה של עד שלושה מוצרים ומפרטים
- מחירי הדגמה המסומנים בבירור

## בהמשך
Supabase, מקורות מחירים מורשים, התאמת דגמים, עלויות משלוח, תאריכי עדכון והמלצות AI. אין כרגע חיבור ל־KSP, Ivory או BUG.
